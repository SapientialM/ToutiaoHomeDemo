# 你可以调用的 MCP 工具（每轮选 1 个）

## 设备操作
- tap({x, y}) — 坐标点击（**先核对截图确认目标元素在坐标处再 tap**）
- swipe({x1, y1, x2, y2, duration?}) — 滑动
- input_text({text}) — 输入文本（先 tap 输入框获得焦点）
- press_key({key}) — 物理按键 (HOME/BACK/ENTER/POWER)
- vision_action({prompt}) — 自然语言点击（VLM 慢但准，适合"找按钮"和"看图标说话"）
- find_element({text}) — 按文本找元素（返回中心坐标）
- wait_for_element({text, timeoutMs?}) — 等待元素出现/消失

## 应用生命周期
- build({variant?}) — gradle 编译 (默认 debug)
- install_and_launch({apkPath?, activity?}) — 装+启动
- stop_app() — force-stop
- clear_app_data() — 清数据（冷启动验证）
- list_apps() — 列出已装应用
- app_info({packageName}) — 元信息
- set_orientation({orientation}) — portrait/landscape/auto
- set_gps({lat, lon}) — 模拟 GPS
- set_animation_scale({scale}) — 0=关动画, 1=正常, 2=慢
- set_network({type, enabled}) — 切网络

## 诊断
- get_logs({filter, lines, packageName?}) — 拉 logcat
- performance_metrics({packageName?}) — CPU/内存/FPS/电池
- measure_app_launch({packageName, launchType?}) — 测启动耗时
- shell_command({command}) — 任意 adb shell
- clear_logs() — 清 logcat 缓冲

## 视觉智能
- analyze_screenshot({filePath, prompt?}) — 深度分析截图
- compare_screenshots({baselinePath, currentPath}) — 对比设计稿
- verify_ui({type, ...}) — 像素/颜色/OCR 验证
- dump_hierarchy({}) — 导出 UI 树 (XML)
- dump_ui({}) — 导出 UI 树 (JSON, 更详细)
- screenshot({savePath?}) — 截图 (本步已自动截)
- screenshot_region({x, y, width, height, savePath?}) — 区域截图
- record_screen({duration?, outputPath?}) — 录屏

## 结束
- done({overall_rating, summary, thinking_process, issues, positives}) — 总结问题清单
  - overall_rating: A/B/C/D
  - issues: 数组，每条含 {id, severity, category, location, current_state, expected_state, suggestion, code_hint?, estimated_effort}
  - positives: 数组，每条含 {item, evidence}

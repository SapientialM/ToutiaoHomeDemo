## 7. 答辩准备

### 7.1 时间分配（30 分钟）

| 时段 | 时长 | 内容 |
|------|------|------|
| 实机演示 | 5 min | 启动 -> 频道切换 -> 详情页 -> 视频 -> 商城 -> 任务 -> 我的 |
| 设计讲解 | 10 min | 架构 -> Paging3 -> 详情页三级兜底 -> MCP 工具集 |
| 评委问答 | 15 min | 详见下表 |

### 7.2 重点准备问答

| 问题 | 准备答案 |
|------|----------|
| 首页数据怎么来的？ | AI Mock 合成 2400+ 条新闻，零真实信息，完全脱机可跑 |
| 为什么用 MVI 不用 MVVM？ | 复杂信息流状态多（频道 / 筛选 / 分页 / 刷新），单一 State 集中管理更清晰 |
| MCP 工具怎么设计的？ | 原子化 + JSON 标准输出 + 6 要素 description + Minimax 视觉 LLM |
| 性能怎么优化的？ | 先量后优：@Immutable / remember / WAL / channel 索引 / CachePolicy |
| 详情页为什么三级兜底？ | OkHttp 抓不到 -> Jsoup 抽不到 -> LLM 兜底 -> Mock 兜底；保证任何情况有内容 |
| AI 写代码你审不审？ | 100% 审，每段过 lint + 单测 + 实跑 |
| Mock 切换真实数据怎么改？ | 只需在 Hilt Module 切换 RealRemoteDataSource，Repository 零改 |

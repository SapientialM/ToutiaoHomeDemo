# 视频录制剧本

> **用途**：字节跳动客户端工程训练营项目验收视频  
> **目标时长**：8-10 分钟  
> **录制建议**：屏幕录制 + 旁白（可用 macOS QuickTime Player 或 OBS）  
> **输出分辨率**：1920×1080 或更高，确保代码和 App 界面清晰  

---

## 录制前准备

### 环境检查清单

| 检查项 | 状态 | 说明 |
|--------|------|------|
| Android 模拟器 / 真机 | ☐ | 已安装 ToutiaoFeedDemo APK，App 可正常运行 |
| IDE（Android Studio） | ☐ | 已打开项目，关键文件已在标签页 |
| Claude Code Terminal | ☐ | 已 `cd` 到项目根目录，MCP Server 已配置 |
| PM Monitor CLI | ☐ | 已 `cd skills/monitor && python main.py` 就绪 |
| 设计稿文件夹 | ☐ | `design/` 目录可快速打开 |
| 浏览器 / 飞书文档 | ☐ | 性能报告页面可快速切换 |
| 桌面清理 | ☐ | 关闭微信、邮件等无关应用，保持桌面整洁 |

### 窗口布局预设（关键）

**布局 A（产品演示阶段）**：
- 主窗口：Android 模拟器（居中，约 60% 屏幕宽度）
- 无需其他窗口

**布局 B（代码讲解阶段）**：
- 主窗口：Android Studio（全屏或 80% 宽度）
- 右侧可留终端小窗口

**布局 C（PM Agent 演示阶段）**：
- 左半屏：Claude Code Terminal（50% 宽度）
- 右半屏：PM Monitor CLI（50% 宽度）
- 下方小窗：Android 模拟器（可叠在角落或快速切换）

**布局 D（性能数据阶段）**：
- 主窗口：浏览器或 Markdown 预览（全屏）

> **提示**：macOS 可用 Magnet 或 Rectangle 快速分屏；录制前先把各窗口调到合适大小，避免录制中频繁调整。

## 常见问题预案

### Q1：录制中 App 崩溃或卡住怎么办？

**预案**：
1. 立即停止录制
2. 杀掉 App 进程，重新 `install_and_launch`
3. 从上一个 Part 的结尾重新录制，后期剪辑拼接

### Q2：PM Agent 工具执行太慢（VLM 调用 10 秒+）？

**预案**：
1. 等待期间用讲解词填充（"PM 正在调用视觉模型分析截图，这个过程大约需要几秒钟"）
2. 或提前预演一次，确保流程通畅后再正式录制
3. 最坏情况：改用 `pm_review`（单次调用，比 `pm_explore` 快）替代 `pm_explore`

### Q3：Monitor CLI 没有实时显示？

**预案**：
1. 检查 `pm_trace.jsonl` 是否有写入
2. 确保 Monitor CLI 在 MCP Server 启动前就已运行
3. 备用方案：不用 Monitor CLI，直接在 Terminal 中 `tail -f pm_trace.jsonl`，效果稍差但可用

### Q4：Claude Code 没有调用 PM tools？

**预案**：
1. 在 Claude Code 的 project prompt 中明确注入："你可以调用 pm_review、pm_explore、pm_discuss 等工具来与项目 PM 协作"
2. 或直接手动输入 tool call（如剧本中所示），不依赖 Claude 的主动性

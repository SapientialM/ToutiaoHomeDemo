# 仿今日头条首页 - PM 审查 Checklist

> 给 AI 产品经理用的"判断标准"。审查时对照此清单逐项过。

## 一、数据加载
- [ ] 首屏数据能否成功加载
- [ ] 加载失败时是否有错误提示（不是空白）
- [ ] 加载中是否有 loading 状态
- [ ] 加载是否流畅（不是卡顿几秒才显示）
- [ ] 网络异常时是否有友好提示
- [ ] 是否有空数据状态（empty state）

## 二、卡片展示
- [ ] 卡片内容是否完整（标题、来源、评论数、时间）
- [ ] 图片是否能正常显示
- [ ] 图片加载中是否有占位图
- [ ] 图片加载失败是否有 fallback（破图标或重试）
- [ ] 卡片间距是否合理
- [ ] 字体大小、行高是否符合阅读习惯
- [ ] 来源/时间戳格式是否一致
- [ ] 多图卡片布局是否正确
- [ ] 长标题是否截断/换行处理

## 三、交互
- [ ] 下拉刷新是否可用
- [ ] 下拉刷新是否有视觉反馈（指示器）
- [ ] 上拉加载更多是否可用
- [ ] 加载更多时是否有 loading 提示
- [ ] 卡片点击是否有响应
- [ ] 长按是否有合适反馈
- [ ] 滚动是否流畅（无明显卡顿）
- [ ] 列表触底时是否自动加载
- [ ] 重复点击是否防抖

## 四、状态管理
- [ ] loading / error / success / empty 四种状态是否齐全
- [ ] 状态切换是否平滑
- [ ] 异常状态是否给用户出路（重试按钮）
- [ ] 多个并发请求时状态是否正确

## 五、视觉规范
- [ ] 颜色使用是否一致（主色/辅色/警示色）
- [ ] 字号是否分级别（标题/副标题/正文/辅助）
- [ ] 是否有不必要的分割线
- [ ] 暗色模式适配（如有）
- [ ] 状态栏/导航栏适配
- [ ] 横竖屏适配

## 六、架构与代码（如果能看到代码）
- [ ] 数据流是否单向、可追踪
- [ ] 状态管理是否集中
- [ ] 关键逻辑是否有注释
- [ ] 是否避免了硬编码
- [ ] 协程作用域使用是否正确

## 七、特殊加分项
- [ ] 是否实现 Room/SQLite 数据库存储
- [ ] 是否支持离线浏览
- [ ] 是否有预加载（prefetch）
- [ ] 是否有图片缓存策略
- [ ] 是否有埋点/分析
- [ ] 是否无障碍适配（TalkBack）
